Detrás de MrRebujito.

De un proyecto de aula a una API REST documentada y comprobable.

2.º DAM / JAVA 17

Una API de feria con reglas de verdad.

El proyecto conserva las entidades originales: casetas, socios, ayuntamientos, productos y solicitudes de licencia. El backend real aplica reglas de acceso por rol, comprueba el aforo y limita las aprobaciones al cupo municipal.

Ver el backend en GitHub

Arquitectura

01Java 17 / Spring Boot 3.5
02Spring Data JPA / PostgreSQL
03JWT y Spring Security
04JUnit y GitHub Actions
05Swagger / OpenAPI
Sobre esta versión web

Es una simulación estática para explorar el funcionamiento sin instalar Java o PostgreSQL. Los datos de ejemplo y los cambios se guardan solo en este navegador. No se realizan gestiones municipales reales ni se emiten licencias oficiales. Para comprobar la seguridad y la persistencia reales, ejecuta el backend.
